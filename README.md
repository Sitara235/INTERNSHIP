# 📊 Investment Analysis Dashboard - Cognizant Project

This project is a comprehensive investment data analysis and visualization dashboard developed as part of a Cognizant initiative. It explores investor behavior across various investment types (Equity, Government Bonds, Gold, Debentures, etc.) with breakdowns based on gender, investment duration, and source of investments.

## 🧠 Project Goal

The primary goal of this project is to:

* Analyze and explore investment trends using real-world or simulated investment data.
* Understand how different demographics (e.g., gender) influence investment behavior.
* Visualize investment avenues, reasons, and objectives.
* Provide actionable insights via an interactive dashboard using data visualization techniques.

---

## ✅ Achievements

* Explored and summarized investment data across 7 pages.
* Calculated average investments in key financial instruments like:

  * Government Bonds
  * Equity
  * Gold
  * Debentures
  * PPF
* Created visual, gender-based investment insights.
* Developed correlation analysis between reasons, avenues, and saving objectives.
* Analyzed frequency and patterns of investment duration.
* Presented the source of each investment type in an intuitive donut chart.
* Delivered an overview page summarizing all insights for quick reference.

## 📄 Project Structure

### **Page 1: Data Exploration & Summary**
